# Ajuste de degradê mobile

Foi aumentado levemente o degradê apenas nas extremidades da seção inicial no celular:

- topo: escurecimento suave para integrar a navbar ao fundo;
- centro: permanece transparente para preservar a visibilidade da logo;
- parte inferior: escurecimento progressivo para integrar os botões e a transição para a próxima seção;
- desktop: não foi alterado.

O efeito usa apenas um gradiente CSS estático, sem impacto relevante no desempenho.
