# Otimização mobile ultraleve

- Nova imagem enviada aplicada somente na versão mobile.
- Imagem convertida para WebP 1200x1200 com alta nitidez e baixo peso.
- Fundo mobile pré-carregado para aparecer rapidamente.
- Removido o observador JavaScript de animações durante a rolagem.
- Animações de entrada desativadas apenas no celular.
- Seções abaixo da dobra usam `content-visibility: auto` para não serem renderizadas antes da hora.
- Sombras e repinturas de elementos fixos foram simplificadas no celular.
- Projeto passou a usar somente uma família de fonte, reduzindo downloads.
- Efeitos do desktop foram preservados.
